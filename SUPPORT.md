# Support

## Getting Help

Use GitHub Discussions for general questions and GitHub Issues for reproducible bugs.

Before opening an issue:

- Check the README and FAQ.
- Search existing issues.
- Review `%AppData%\SimpleLauncher\Logs\simplelauncher.log`.

## What to Include

- SimpleLauncher version.
- Windows version.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Sanitized logs if available.

Do not include private usernames, child names, device names, or secret configuration values.
