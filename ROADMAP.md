# Roadmap

## v1.0

- Stable fullscreen launcher.
- JSON configuration and migration from legacy INI.
- Add, remove, rename, search, sort, favorite, and categorize apps.
- PIN-protected settings and exit.
- Backup, import, and export configuration.
- CI, tests, documentation, and signed release artifacts.

## v1.1

- Polished settings window.
- Drag-and-drop icon positioning.
- Better theme editor.
- Startup with Windows management.
- Accessibility pass for keyboard navigation, contrast, and screen-reader labels.

## v2.0

- Optional shell replacement workflow with recovery documentation.
- Touch-first mode for tablets and kiosks.
- Localization infrastructure.
- Policy templates for schools and managed public computers.

## Future

- Plugin system for custom tiles, policies, and launch providers.
- Central configuration distribution.
- Optional update checker.
