# Roadmap

SimpleLauncher is still in pre-1.0 development. Public releases follow semantic versioning with `0.x` versions until the launcher is stable enough for a 1.0 commitment.

## v0.2

- Improve the Settings experience.
- Add remove and rename workflows directly in the launcher UI.
- Expand configuration import, export, backup, and restore polish.
- Improve keyboard navigation and accessibility labels.

## v0.3

- Add drag-and-drop icon positioning.
- Add richer theme and background controls.
- Add startup-with-Windows management.
- Improve kiosk recovery documentation.

## v1.0

- Stable fullscreen launcher.
- Reliable JSON configuration and legacy migration.
- Add, remove, rename, search, sort, favorite, and categorize apps.
- PIN-protected settings and exit.
- Backup, import, and export configuration.
- CI, tests, documentation, and reproducible release artifacts.

## Future

- Optional shell replacement workflow with recovery documentation.
- Localization infrastructure.
- Touch-first mode for tablets and kiosks.
- Plugin system for custom tiles, policies, and launch providers.
- Central configuration distribution.
- Optional update checker.
